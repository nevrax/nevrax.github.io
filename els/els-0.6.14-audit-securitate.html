Aplicația evaluată

ELS este un editor de diagrame pentru reprezentarea infrastructurilor și a conexiunilor dintre componente. Aplicația rulează în browser dintr-un fișier HTML care include interfața, stilurile CSS și codul JavaScript.

O diagramă conține noduri, containere, mașini virtuale, firewall-uri și segmente de rețea. Nodurile pot avea porturi pe laturile nord, est, sud și vest. Conexiunile pot avea puncte intermediare, etichete, săgeți și stiluri de linie. Editorul oferă selecție, mutare, redimensionare, aliniere pe grilă, grupuri de noduri sincronizate și istoric Undo/Redo.

Modelul diagramei poate fi importat și exportat ca JSON ELS. Selecțiile pot fi copiate și lipite ca text JSON. Exporturile de prezentare sunt SVG, PNG, JPG și Mermaid. Biblioteca de diagrame și preferințele sunt păstrate în localStorage, în profilul browserului și pentru originea la care este deschis editorul.

Modelul JSON descrie elementele grafice și relațiile dintre ele. Aplicația evaluată nu conține un serviciu de autentificare, un server de colaborare sau un mecanism de aplicare a configurațiilor pe echipamente. Serverul local și conexiunea CDP sunt folosite pentru dezvoltare și executarea probelor; fișierul HTML poate fi deschis și direct prin file://.

Scop și metodologie

Evaluarea acoperă documentul HTML ELS, codul JavaScript și CSS încorporat, procesarea datelor de diagramă și comportamentul observabil în browser. Sunt utilizate analiză de sursă asistată de AI, parcurgere AST, verificări CSS și probe dinamice cu date sintetice în contexte Chromium izolate.

Sursele de date neîncrezute considerate sunt fișierele importate, textul lipit din clipboard și conținutul stocării locale. Obiectivele verificărilor sunt prevenirea execuției de script din date, limitarea injecțiilor de stil și a cererilor externe, validarea structurii modelului și păstrarea integrității diagramei la erori.

Antetele unui server de producție, extensiile browserului, compromiterea dispozitivului și securitatea programelor terțe care deschid exporturile sunt în afara evaluării. Acesta este un raport tehnic de verificare, fără certificare de către o organizație de audit independentă.

Constatări și limite

SEC-01 · Integritatea modelului la eșecul importului

Stare: remediat și verificat. Un import care eșua în timpul randării putea înlocui modelul din memorie înainte de a raporta refuzul. Implementarea evaluată limitează adâncimea înainte de mutație și restaurează modelul, grila, vederea și selecția dacă o etapă ulterioară eșuează. CAP-01, CAP-02, CAP-03 și TX-01 verifică scenariul adversarial, limita 64/65, clipboardul și o eroare DOM provocată după validare, inclusiv păstrarea salvării și a istoricului Undo.

Confidențialitatea stocării locale

Biblioteca și preferințele sunt persistate fără criptare implementată de ELS. Scripturile de aceeași origine și utilizatorii cu acces la profilul browserului pot accesa aceste date. Stocarea locală nu constituie un mecanism de autentificare sau de control al accesului. Separarea originilor și protecția profilului sunt responsabilități ale mediului de utilizare.

Politica CSP și găzduirea

Scripturile integrate sunt autorizate prin hash. Stilurile inline sunt permise pentru stilurile dinamice ale editorului. Directiva connect-src permite adresele locale HTTP 127.0.0.1:8765 și localhost:8765 pentru reîncărcarea automată din mediul de dezvoltare. Codul EventSource este condiționat de protocol, gazdă și port.

Directiva frame-ancestors nu este aplicabilă într-un meta CSP. O politică de interzicere a încadrării în iframe trebuie furnizată prin antete HTTP când aplicația este găzduită. Antetele unui server de producție nu sunt verificate de aceste probe.

Limitele probelor

Rezultatele demonstrează condițiile exercitate, fără garanția absenței tuturor vulnerabilităților. Evenimentele clipboard sunt sintetice. Inspecția SVG acoperă XML-ul exportat, fără a evalua toate programele care îl pot interpreta. Proba file:// acoperă Chromium din mediul indicat; alte browsere și sisteme nu sunt testate. Nu s-a executat fuzzing nelimitat sau verificare formală.
